# TechNeeds – Mentorship & Learning Platform

TechNeeds is a web platform focused on making mentorship and learning opportunities more accessible to students. It brings different learning-related features together in one place, giving students a space to connect with mentors, explore programmes, attempt quizzes and work on projects.

This project was developed during a hackathon as part of a challenge to completely reimagine an existing website. We used the original TechNeeds website as our starting point and worked on giving it a new design, improved user experience and additional functionality.

## About the Hackathon

The hackathon problem statement was to take an existing website and reimagine it completely.

We were given an existing project to work with, but the challenge was not just to change its colours or rearrange a few sections. We wanted to rethink how the platform looks, feels and works for its users.

Our team worked on the frontend experience, backend functionality and overall presentation of the idea. Everyone took responsibility for a different part of the project, and we brought those contributions together to create our hackathon submission.

## What TechNeeds Offers

Some of the main features of the platform include:

- **Student Dashboard:** A dedicated area where students can access their learning activities.
- **Mentor Management:** Features for managing mentors and connecting them with programmes.
- **Programme Management:** Create and manage learning programmes.
- **AI Profile:** An AI-powered profile feature designed to assist users with their profiles.
- **Quiz Module:** Allows students to attempt quizzes and test their understanding.
- **Project Submission:** Provides a space for students to submit their project work.
- **Admin Panel:** Helps manage mentors, programmes and other platform activities.
- **Authentication:** Login functionality for different types of users.

## Getting Started

Want to run the project locally? Follow these steps.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- MongoDB

### 1. Clone the repository

```bash
git clone https://github.com/tejanshtiwari/techneeds_hackathon.git
```

Move into the project directory:

```bash
cd techneeds_hackathon
```

### 2. Set up the frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend development server should now be running.

### 3. Set up the backend

Open another terminal and navigate to the backend folder:

```bash
cd backend
npm install
npm run dev
```

Make sure MongoDB is running and the required environment variables are configured before starting the backend.
